# jbrowse-plugin-msaview

A multiple sequence alignment and phylogenetic tree viewer for JBrowse 2, linked
column by column to the genome. It packages
[react-msaview](https://github.com/GMOD/react-msaview), whose
[user guide](https://github.com/GMOD/react-msaview/blob/main/docs/user_guide.md)
covers the viewer itself.

## Use it

- Right-click a gene and choose "MSA view...": precomputed orthologs (NCBI,
  PANTHER), the gene's UniRef cluster, or a phmmer/blastp search at EBI
- Or open an alignment of your own: FASTA, Stockholm or Clustal, with an
  optional Newick tree
- Every launch is also a session-spec URL, so a link can open the same view

It is installed by default on https://genomes.jbrowse.org.
